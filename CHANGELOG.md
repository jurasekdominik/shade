# Changelog

Releases of the Shade package, newest first. While the version is 0.x a component or a fix is the next patch; a public API break requires a minor release.

| Version | Changes |
| --- | --- |
| 0.8.0 | Extension points; an explicitly requested minor that groups non-breaking work, no public API break. EditableTable: ribbon Decimals and Suffix, ribbon tabs, hidden fields, paper formats and app column fields, a row menu and `RowActions`, toolbar and Add rows placement and items, and `CellTemplate`, `HeaderTemplate` and `FooterTemplate` for your own cell, heading and footer content. Menus take `MenuEntry` items. Sidebar: `Entries`, a parameterless constructor, entry visibility, enabled state, badge, tooltip and headings, `Header`, `Footer` and `ShowHistory`. Dialogs: `Ask.Choose`, `ChoiceOption` and a public `Dialog(title, body, options)`. SummaryCards: `SelectedKey`, `Selectable`, and per-card tooltip, disabled state and command. Web page counterparts for each. |
| 0.7.2 | Optional EditableTable paper dimensions beside the format caption, removing the bottom note row while preserving the default layout. Bindable native API and matching web option; no public API break. |
| 0.7.1 | Consistent picker popup dismissal, outside-click pass-through and lifecycle cleanup; pointer versus keyboard focus styling. Fix expanded EditableTable ribbon tab visibility and formula heading spacing in native and web controls. No public API break. |
| 0.7.0 | Unified app-agent and contribution guidance, shared gap reporting and fix adoption, focused iterative testing with user-provided UI evidence, CI documentation/package checks, and line-ending/culture-safe documentation generation. Requested minor release; no public API break. |
| 0.6.5 | Independent paper preview/full-width editing, measured localized ribbon fields, compact width displays that preserve exact geometry, content-sized group flow and adaptive expanded ribbon. |
| 0.6.4 | Fix localized ribbon numbers, invalid-draft completion, custom font-size choices and duplicate formula-source labels. Preserve resize-owner selection, validate pending keystrokes on Done, and define Escape/column-change draft behavior. No new public API or dependencies. |
| 0.6.3 | Integrated EditableTable column ribbon (`ShowColumnEditor`), alignment, units, formulas, typography, bounded sizing and paper formats in C# and the web preview. Bindable paper setup, safe unit drafts and rechecked removal permissions; sliding tabs and connected dropdown borders. |
| 0.6.2 | Native column/cell alignment overrides, symmetric resize hit targets, stable invalid-input row height, and contained menu scrolling. |
| 0.6.1 | SearchChoice with accent match highlighting and virtualized object/ID options; menu focus, wrapping sidebar branding, table validation/footer fixes, Ctrl-drag design, wider resize targets, compact action placement, column typography, and synchronized accent helpers. |
| 0.6.0 | Breaking migration to native action/toggle/checkbox contracts with Shade themes and artwork. Bindable picker/menu APIs, ordered short-list selection, editable pair rows with draft-safe duplicate validation, native clear/remove/undo targets, host-theme composition and broader bindings. Includes all unreleased 0.5/0.5.1 configuration, localization, validation and table-performance work below. See the adoption guide before upgrading. |
| 0.5.1 (included in 0.6) | Additive multi-selection API: bindable options/selection/captions, immutable snapshots, native checkbox automation, keyboard/typeahead navigation and popup lifecycle cleanup; PairTable.Ensure deduplicates repeated new names. Preserves the 0.5 breaking migration. |
| 0.5.0 (included in 0.6) | Breaking: configurable runtime font and metric properties. Bindable field validation/read-only state and date limits; count-aware localization; culture-aware table parsing and validated edit notifications; observable/bindable collections; row virtualization and cached measurements; cached footer aggregates; async button actions; live built-in language refresh; bindable list values/action labels; native summary/calendar/tab semantics and keyboard focus; broader 2x metric coverage. `SummaryCards` now derives from `Panel`. See the adoption guide for migration and limits. |
| 0.4.6 | `EditableTable`: `CanResize` and `CanEditFooter`, independent of `Design` and `IsReadOnly`; `Column.Display` formats numbers (culture, currency) for typed values, computed values and footers, and the widths measure it; `CurrentColumn` can be set; `CanRemoveColumn` is asked before a column is removed. Footer labels are measured translated. The accent picker's names and swatch tooltips, and the colour grid's labels, go through `Look.Translate`. |
| 0.4.5 | `Look.Translate`: every built-in label (buttons, tooltips, menus, the calendar, the table's actions, dialog buttons, the colour grid and accent picker) goes through it, keyed by its English text; `Look.Culture` names the calendar's months and days. `Menu.Danger(text)` marks a danger item in any words; danger is told before translation. `EditableTable`: `Kind.General` for numbers and text codes together, kept as typed and aligned per cell; a row's unit that isn't in `Units` shows as stored, with room for it, and a click moves it to the list. |
| 0.4.4 | `EditableTable`: column widths `Sizing` Fit (content, never cut), Fill (the room left) or Fixed, with `MinWidth` and `MaxWidth`; a resize sets a Fill column's minimum. Cells are text with one moving editor (caret where clicked, Tab to the next cell); selection, sorting and new rows update in place, keeping focus and caret; the focus ring no longer stays behind. The heading and footer stay put while the rows scroll, the scroll bars outside the grid. The current column's heading has the accent tint instead of an underline. A right-click on a row number opens the row menu. The designer's grip shows on hover, so headings keep their width. Much faster with many rows. Fix: `DateField`'s calendar icon opened and closed the month in one click. |
| 0.4.3 | `EditableTable` counts in decimals: computed columns and footers add money up to the cent, as an export does (`Exact`, `FooterValue`; `Value` stays, as a double). `Calculate`: an app with its own money rules supplies a computed column's values, and `FromTerms` keeps the table's formula for the columns it leaves. |
| 0.4.2 | Fix: `EditableTable`'s footer shows its function and value on one baseline, right-aligned in number columns, as on the live page. |
| 0.4.1 | The controls the live page previewed in 0.4.0. `DateField`: year, month and day are blocks to type in (digits move on, Up/Down change, Ctrl+V reads a day); a click anywhere opens the month; Alt+Down or F4 for the keyboard. `DateRangeField`: a start and an end in one field, the days between coloured in the month. `EditableTable`: cells edited in place, values with units, computed columns of any number of columns, a footer (Sum, Average, Min, Max, Count), column resizing, three-state sorting, row selection and a row menu, several rows added at once, and a design mode that is the table designer. Search matches: `Build.Mark`, `Workbench.Mark` on a table, and the suggestion list marks the typed letters. |
| 0.4.0 | Breaking: `ButtonKind.Soft` removed (it painted as `Normal`), `GearButton` removed (unused). `DESIGN.md` follows the design.md format, ships in the package and has *Choosing a component*; apps get a rules block and a CI check (*Rules for an app's agents*). Contrast: small accent text reads at 4.5:1 on its tint too; the Danger button uses the Danger tint and Danger text roles. One keyboard focus rule for buttons, dropdowns, dates and the designer. Icon `Ellipsis`. The live page has subsections and previews the next controls: date blocks with a range, search highlights, the editable table with its designer. The public API is now listed as shipped. |
| 0.3.3 | `ModeSwitch`: Light, Dark or System (the computer's setting, followed live) as one segmented control; `ModeSwitch.Apply` restores a saved choice. Icons `Sun`, `Moon`. Fix: `TableDesigner`'s RowFill, Locked and EmptyText draw again when set after the rows. The live page's top-bar switch is the same component, with System. |
| 0.3.2 | `TableDesigner`: a table's columns over preview rows; a header is dragged from anywhere on it to the gap between two columns (an accent line marks it), fields drop in from other controls (`DragSource`); right-click menu (insert before/after, remove), Ctrl+Left/Right moves. |
| 0.3.1 | `DateField`: a day, typed (2026-10-24 or 24.10.2026) or picked in the month its calendar icon opens; keyboard; Min/Max; weekends marked red (default), grey or not at all (`WeekendMark`). Icons `Calendar`, `ChevronRight`. |
| 0.3.0 | `AccentPicker`: the accent as a settings row (dot and name, Custom hex field, curated swatches; the field opens the colour helper), with `AccentPicker.Apply(value)` to restore a saved accent at start-up. |
| 0.2.2 | Fix: a dropdown (and a multi-choice) closed by a click on it keeps its hover border at once, instead of its resting border until the pointer moves. |
| 0.2.1 | Fixes: a dropdown's text no longer moves when its list opens, and its focus ring shows only for keyboard focus (not after a pick by the pointer); a click on the background takes the focus out of a field (`Look.Apply`). |
| 0.2.0 | An app's own mark: `Look.Apply(..., mark: (g, box, colour, phase, icon) => ...)` draws it wherever Shade draws the mark (window icons, `Look.Mark`, the sidebar, dialogs); `Look.PaintMark`. `StateToggle.UnknownText`: the words while the state is unknown. |
| 0.1.0 | The first package. |
