# Bundled Inter

Source: [Inter v4.1, official InterVariable.ttf](https://github.com/rsms/inter/blob/v4.1/docs/font-files/InterVariable.ttf).
Original Git blob SHA: `4ab79e0102bbe0ffa1ed879b13e52ac8c6487833`.

The original font was verified against that SHA. These static TrueType
instances use optical size 14 and weights 400, 500, 600 and 700. They were
generated with fontTools' `instantiateVariableFont`, with the family/style
names set to Inter / Regular, Medium, SemiBold and Bold for embedded loading.
All original copyright and license metadata is retained. See [OFL.txt](OFL.txt).

Avalonia embeds the fonts under `Assets/Inter`; no Windows font installation
or runtime download is required.
